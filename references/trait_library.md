# 标准化词库

画像与岗位比对必须使用统一的标准化特质词，保证两部分可程序化匹配。

## 性格特质词库（traits_ranked 使用）

| 特质词 | 含义 | 典型对应岗位方向 |
| --- | --- | --- |
| 沟通影响 | 表达、说服、人际影响力 | 市场、销售管理、公关、人力 |
| 执行落地 | 责任心强、按计划推进、交付稳定 | 运营、行政、项目助理 |
| 逻辑分析 | 数据敏感、推理、结构化思考 | 数据分析、金融、咨询、产品 |
| 创意表达 | 内容创作、设计、策划 | 新媒体、设计、广告、内容运营 |
| 技术钻研 | 编程、工具、工程问题解决 | 研发、测试、技术支持 |
| 组织协调 | 统筹、多任务管理、推动协作 | 项目管理、运营、人力、行政 |
| 竞争驱动 | 目标感强、抗压、追求结果 | 销售、商务、增长 |
| 服务导向 | 乐于助人、共情、耐心 | 人力、客服、教育、运营 |
| 稳定偏好 | 求稳、规律、低风险 | 行政、财务、内勤 |

## 能力标签词库（ability_scores 使用）

| 能力标签 | 说明 | 对应自评题 |
| --- | --- | --- |
| 沟通 | 表达/说服/汇报/人际 | 第 9 题 |
| 数据分析 | 数据敏感/逻辑/信息处理 | 第 10 题 |
| 创意 | 写作/设计/策划/内容 | 第 11 题 |
| 组织协调 | 多任务/项目推进/统筹 | 第 12 题 |
| 技术 | 编程/软件/工程实操 | 第 13 题 |
| 学习（可选） | 新知识吸收速度 | 附加题 |

## 价值偏好词库（value_preferences 使用）

- 薪资_vs_成长：高薪优先 / 成长优先 / 尽量平衡
- 加班接受度：完全不能接受 / 偶尔可接受 / 可接受高强度
- 稳定性偏好：偏好稳定 / 偏好挑战 / 中性

## 岗位特质拆解原则

- 岗位核心特质必须映射到上表标准化特质词，不使用口语化描述。
- 区分「硬性门槛」（学历、证书、专业）与「软性特质」（上述词库）。
