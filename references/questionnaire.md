# 18 道题题库

三层结构：**兴趣方向（8 题）→ 能力自评（5 题）→ 硬约束（5 题）**

## 第一层：兴趣方向（8 题）

目标：推断性格特质排序、匹配方向。每题给出 3-5 个选项，选项映射到标准化特质词（见 trait_library.md）。

1. **什么样的工作内容最能让你有成就感？**
   - A. 说服别人、影响他人做决定 → 沟通影响
   - B. 把一件事从头到尾做完 → 执行落地
   - C. 分析数据、找到规律 → 逻辑分析
   - D. 产出作品、被很多人看到 → 创意表达
   - E. 解决一个技术难题 → 技术钻研

2. **学生时代你投入最多时间的课外活动是？**
   - A. 社团/学生会组织活动 → 组织协调
   - B. 比赛/竞赛/辩论 → 竞争驱动
   - C. 写文章/做设计/剪视频 → 创意表达
   - D. 打游戏/研究工具软件 → 技术钻研
   - E. 基本都在学习备考 → 执行落地

3. **你更喜欢哪种日常状态？**
   - A. 每天面对不同的人和事，变化多 → 沟通影响
   - B. 按计划推进，事情可控 → 执行落地
   - C. 独自研究问题，深度专注 → 逻辑分析 / 技术钻研
   - D. 自由发挥，没有固定流程 → 创意表达

4. **以下哪类课程/内容你学起来最轻松、最享受？**
   - A. 市场营销、心理学、传播学 → 沟通影响
   - B. 数学、统计学、经济学 → 逻辑分析
   - C. 设计、文学、艺术 → 创意表达
   - D. 编程、电子、机械 → 技术钻研
   - E. 管理学、项目实践 → 组织协调

5. **你理想的工作节奏是？**
   - A. 快节奏、多任务、有挑战 → 竞争驱动 / 执行落地
   - B. 稳定规律、少加班 → 稳定偏好
   - C. 前期松后期紧、以结果为导向 → 执行落地
   - D. 弹性自由、靠自律 → 创意表达 / 技术钻研

6. **你是否享受「帮助别人解决问题」类的工作？**
   - A. 非常享受，有成就感 → 服务导向（匹配方向：人力、运营、咨询）
   - B. 可以，但不想成为主旋律 → 中性
   - C. 不太喜欢，更喜欢对事不对人 → 逻辑分析 / 技术钻研

7. **如果给你一个月的自由时间，你会用来？**
   - A. 学一门新技能（乐器/剪辑/编程）→ 技术钻研 / 创意表达
   - B. 去旅行、接触不同的人 → 沟通影响
   - C. 研究一个感兴趣的问题/项目 → 逻辑分析
   - D. 找份兼职赚钱 → 执行落地 / 竞争驱动

8. **想象 3-5 年后的自己，最接近哪种状态？**
   - A. 带团队、做管理 → 组织协调 / 沟通影响
   - B. 成为某个领域的专家 → 逻辑分析 / 技术钻研
   - C. 有自己的作品/账号/项目 → 创意表达
   - D. 稳定工作、生活平衡 → 稳定偏好
   - E. 高薪、快速上升 → 竞争驱动

## 第二层：能力自评（5 题）

目标：生成能力标签分数。每题按 1-5 分自评（1=很弱，5=很强）。

9. **沟通表达能力**（口头表达、说服、汇报、人际交往）：__ 分
10. **数据分析能力**（Excel/数据敏感度/逻辑推理/信息处理）：__ 分
11. **创意与内容能力**（写作、设计、策划、内容创作）：__ 分
12. **组织协调能力**（多任务管理、项目推进、统筹资源）：__ 分
13. **技术动手能力**（编程、软件工具、工程实操）：__ 分

> 计分规则：分数 ≥4 记为优势能力；分数 =3 记为中性；分数 ≤2 记为短板（在岗位比对中按短板处理）。
> 可选附加题（不计入 5 题）：**学习能力自评**，用于补充「建议补充的能力」建议。

## 第三层：硬约束（5 题）

目标：生成价值偏好与硬约束，确定排除方向。

14. **目标城市**：你计划在哪个城市工作？请填写具体城市名（如：杭州、深圳、成都、武汉），或直接回复「不限」。
    - 填写城市名 → hard_constraints.city = "用户填写的目标城市名"（如 "杭州"）
    - 回复「不限」→ hard_constraints.city = "不限"
15. **薪资底线**：你能接受的最低月薪（税前）是多少？
    - 填空，填入 hard_constraints.salary_floor
16. **加班接受度**：A. 完全不能接受 B. 偶尔加班可以 C. 为发展可接受高强度加班
    - A → value_preferences.加班接受度 = "完全不能接受"；B = "偶尔可接受"；C = "可接受高强度"
17. **禁忌岗位**：以下哪些岗位类型你坚决不投？（可多选）
    - 销售/地推、夜班/倒班岗、纯体力岗、应酬型岗位、其他（填空）
    - 选中的项写入 exclude_directions 与 hard_constraints.taboo_jobs
18. **成长 vs 薪资**：在「薪资高但成长慢」和「薪资一般但成长快」之间，你更倾向哪个？
    - A. 高薪优先 B. 成长优先 C. 尽量平衡
    - 写入 value_preferences.薪资_vs_成长

## 计分与画像生成规则

- **性格特质排序**：由第一层 8 题的选择频次加权生成，出现次数最多、且与价值偏好一致的特质排最前；稳定偏好类选项会提升「稳定偏好」在价值偏好中的权重。
- **匹配方向**：由 traits_ranked 前 2 位 + 能力分数 ≥4 的能力共同推导（如「沟通影响」+「创意表达」→ 运营/市场/内容方向）。
- **排除方向**：由 hard_constraints 直接推导（如禁忌岗位、目标城市不匹配、薪资底线不满足的岗位方向）。
- **薪资范围**：推荐岗位的薪资范围根据用户填写的目标城市动态生成（参考 salary_reference.md 的城市档位逻辑），不固定任何单一城市。
