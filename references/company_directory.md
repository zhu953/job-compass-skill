# 公司目录与投递入口

> 说明：本文件为静态参考目录，旨在帮助用户快速找到目标岗位的典型雇主。**受限于时效性，不能保证以下公司当前一定在招。** 强烈建议用户结合 BOSS直聘、猎聘、智联招聘的实时搜索，或直接访问公司校招官网确认在招岗位。

## 投递入口模板
- **校招官网入口**：目标公司官网 -> 招聘 -> 校园招聘
- **招聘平台搜索式**：BOSS直聘/猎聘 搜索「岗位关键词 + 城市」
- **招聘平台直达**：智联招聘、猎聘（部分公司有官方企业主页）
- **高校就业网**：目标城市的重点高校就业信息网（如：杭州的浙大就业网）

## 按岗位方向分类

### 一、运营类
- **内容运营 / 新媒体运营**
  - 典型公司：小红书、网易、B站、快手、字节跳动
  - 投递入口：校招官网（如 job.xiaohongshu.com、campus.163.com、jobs.bytedance.com）；BOSS直聘搜「内容运营 + 城市」
- **社群运营 / 用户运营**
  - 典型公司：快手、小红书、阿里系、美团
  - 投递入口：BOSS直聘搜「用户运营 + 城市」；公司校招官网
- **电商运营**
  - 典型公司：阿里系、拼多多、京东、唯品会
  - 投递入口：公司校招官网；猎聘「电商运营 + 城市」

### 二、市场与品牌类
- **市场专员 / 商务拓展**
  - 典型公司：美团、阿里、字节跳动、本地生活服务公司
  - 投递入口：BOSS直聘搜「商务拓展 + 城市」；公司校招官网
- **文案策划 / 品牌助理**
  - 典型公司：奥美、蓝色光标、网易、省广集团
  - 投递入口：公司校招官网；BOSS直聘搜「文案策划 + 城市」

### 三、产品与设计类
- **产品助理 / 产品经理**
  - 典型公司：腾讯、字节跳动、网易、美团、阿里
  - 投递入口：校招官网；BOSS直聘搜「产品助理 + 城市」
- **UI/视觉设计师**
  - 典型公司：网易、字节跳动、各大互联网公司设计部
  - 投递入口：校招官网（需附作品集）；猎聘搜「视觉设计师 + 城市」

### 四、数据与研发类
- **数据分析助理**
  - 典型公司：阿里、字节跳动、美团、各大银行/券商
  - 投递入口：公司校招官网；BOSS直聘搜「数据分析 + 城市」
- **研发工程师**
  - 典型公司：字节跳动、腾讯、阿里、华为、美团
  - 投递入口：校招官网；牛客网（大量内推）

### 五、人力、行政与销售类
- **人力资源专员 / HRBP助理**
  - 典型公司：各大互联网公司、外企、大型国企
  - 投递入口：BOSS直聘搜「HR + 城市」；公司校招官网
- **销售代表 / 顾问**
  - 典型公司：各大B2B公司、电商、金融/保险机构
  - 投递入口：BOSS直聘搜「销售 + 城市」；公司校招官网
- **行政专员**
  - 典型公司：各类大中小型企业
  - 投递入口：BOSS直聘搜「行政 + 城市」；当地人才市场

### 六、管培生/综合类
- **管培生（京东TET、宝洁、联合利华等）**
  - 典型公司：京东、宝洁、联合利华、欧莱雅、各大银行
  - 投递入口：公司校招官网；关注“应届生求职网”汇总信息

## 使用建议
1. **首选Boss直聘**：适合直接沟通、看真实在招岗位。
2. **次选猎聘**：适合找中大型企业、管培生岗位。
3. **校招官网**：最权威，适合大厂投递，但需留意截止时间。
4. **高校就业网**：信息集中，适合本地化求职。
