# Job Compass 选岗罗盘

一个 AI Skill，帮助应届毕业生完成从「不知道选什么岗位」到「判断具体岗位该不该投」的全流程选岗决策。

## 问题

应届生面对海量岗位时，痛点是双重的：自我认知模糊 + 岗位信息过载。现有工具各缺一半——性格测评只给类型标签，不给具体岗位；招聘平台只基于简历关键词匹配，不帮你做自我认知。

## 方案

通过 18 道题（兴趣 8 + 能力自评 5 + 硬约束 5）建立结构化用户画像，输出 5-8 个具体岗位推荐，并对任意岗位做双维度适配分析。

## 核心设计

- **两阶段强制联动**：第二部分必须读取第一部分的画像，禁止孤立分析。
- **双维度判定**：同时判断「特质排名」和「能力分数」，避免“喜欢但不擅长”被误判为匹配。
- **固化推荐率公式**：强匹配 3 分、可匹配 2 分、中间档 1 分、弱匹配 0 分，禁止 AI 临时编权重。
- **AI 冲击风险动态生成**：不照抄静态等级，逐项列出会被替代和不会被替代的工作内容。
- **一票否决规则**：命中硬约束（城市、禁忌岗位、薪资底线）直接降级。

## 测试与迭代记录

在开发过程中，通过实测发现并修复了一个关键问题：
- **问题**：初版算法给用户的匹配度高达 88%，但用户能力全部中等（3/5），存在严重虚高。
- **修复**：固化公式，加入“特质排名 × 能力分数”双维度判定。新公式下匹配度回落到 33% 左右，真实反映了“方向对口，但能力尚未兑现”的现状。
- **体验优化**：针对低分可能带来的沮丧感，在 SKILL.md 中强制加入固定解释规则：“该分数偏低不代表方向错误，而是反映当前能力尚未兑现。方向对口 + 成长空间大，仍值得投递，但需用作品/案例弥补能力证据。”

## 已知局限

- 公司推荐依赖联网搜索，不保证当前在招，用户需以平台实时信息为准。
- 薪资数据为参考值，需核对最新招聘行情。
- 当前环境无招聘平台插件，无法实现实时岗位搜索。

## 如果继续做

- 接入招聘平台 API，实现实时岗位搜索。
- 增加多轮追问，提升画像精度。
- 引入用户反馈，校准推荐率算法。
