# 🧭 Job Compass (求职罗盘)

> 一款基于AI大模型的情境化、个性化求职匹配测评工具
> "告别僵化的选择题，寻找真正适合你的职场DNA。"

## 💡 一、项目背景与痛点洞察 (Why We Build This?)

在当前的求职市场中，存在极其严重的**人岗错配**与**求职焦虑**。通过深度的用户调研与自我剖析（作为跨行求职者的亲身经历），我们发现了以下几个核心痛点：

1. **测评工具僵化**：市面上的传统测评多为“非黑即白”的抽象选择题（如“你内向还是外向？”），忽略了人性的复杂性与场景依赖性。
2. **用户耐心缺失**：动辄上百道的冗长题海，导致用户在测评中途流失，数据采集极其不完整。
3. **结果与求职脱节**：传统测评输出了性格标签，却无法与真实的招聘JD（岗位描述）相结合，导致用户“测了等于白测”，无法指导实际求职。

## 🚀 二、核心差异化设计 (Core Features)

为了与市面上烂大街的测评工具拉开差距，Job Compass 首创了以下核心机制：

* **🔀 双档位灵活测评**：
    * **18题快测版**：主打低门槛、快速定位。满足处于迷茫期、耐心有限的用户，提供初步的人物画像与行业排除法。
    * **80题精测版**：主打深度挖掘、精准匹配。适合有明确目标、渴望深层解读职场性格的用户。
* **🎭 情境化模拟 (Situational Simulation)**：
    * 摒弃传统的“贴标签”式提问。将问题置入真实的职场业务场景中（例如：“当你跟进长达3个月的客户一直不回消息，你会如何反应？”）。测出的是用户在职场高压、复杂沟通下的**真实行为模式**，而非理想化的自我认知。
* **✍️ 自由发挥的“E选项”(AI NLP解析)**：
    * 面对复杂人性，ABCD四个选项远远不够。在关键情境题中强制开放 **“E. 其他（自由输入）”**。我们利用大模型（NLP）解析用户自由发挥的文本，抓取隐藏特质，真正实现“千人千面”。
* **🎯 岗位JD匹配闭环 (Job Description Matching)**：
    * 测评的终点是求职。用户生成“人物画像”后，可输入心仪的岗位JD。系统自动进行语义匹配，输出**匹配度百分比**，并指出用户的优劣势，给出简历优化建议，形成完整的求职闭环。

## 🛠️ 三、技术架构与实现路径 (Technical Architecture)

* **前端交互**：问卷动态渲染引擎（支持快测/精测双轨切换）、E选项文本输入框、雷达图画像展示。
* **核心逻辑**：用户行为数据抽取 -> NLP情感/特征分析 -> 人物画像建模 -> 岗位JD关键词向量匹配。
* **AI引擎设想**：调用大模型API（如文心一言/智谱/OpenAI），进行开放式文本的意图识别与关键能力提取。
* **数据隐私**：严格遵守《个人信息保护法》，用户数据脱敏处理，仅用于本地匹配与画像生成。
